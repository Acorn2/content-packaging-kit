# 输出契约

先交付标题与可复制文案，编辑说明后置。不用公式名称、研究过程和安全声明抢占标题的位置；条件字段不适用就省略。

## 仅标题

按所选平台给三个候选、实际字符数和简短点击理由，推荐一个并比较最接近的候选。用户指定一个就只给一个；不附排期、SEO报告或完整发布包。公式名可在用户要求拆解时补充。

## 完整发布包

每种形式保存一个 Markdown 文件，包含所选平台。按下列骨架组织，不留下空占位：

```markdown
# 内容名称 — 视频 / 图文发布包

原文：路径或用户粘贴内容
覆盖范围：依据哪一稿；必要的删改说明
生成日期：日期

## 主推速览
| 平台 | 主推标题 | 封面短句 |
| --- | --- | --- |
| 所选平台 | 与下方推荐一致 | 实际文案 |

## 平台名称

| 候选 | 标题 | 字符数 | 点击理由 |
| --- | --- | --- | --- |
| A | 实际标题 | 实际计数 | 谁为什么想点 |
| B | 实际标题 | 实际计数 | 实质不同的动机 |
| C | 实际标题 | 实际计数 | 实质不同的动机 |

推荐：编号及一句比较理由。

### 可复制简介 / 描述 / 配文
实际发布文案。

### 话题 / 标签
实际话题或标签。

### 封面与开头
封面文字；视频开头注明沿用 / 改剪 / 需补拍，图文给首屏建议。
按平台需要补分区 / 分类、发布入口、短标题。它们不是话题标签的别名。
仅用户需要且有可靠时间映射时加B站章节，时间依据另注。

## 发布时间
时区、所选平台首选 / 备选 / 休息日窗口、适配理由和依据状态。
无账号数据统一注明待测试；不在各平台重复整张时间表。

## 编辑说明
内容主题：一句话独立说明讲什么。
传播目标与受众：简述策划假设。
关键词：需要时列主要意图及标题 / 简介 / 标签落位，不堆词表。
依据：原文、补充资料与影响本次交付的待确认项；计数口径集中写一次。
研究：仅本次确实联网时列采用的来源、日期、读取范围及具体采用方式。
后续创意：仅有必要时列需补充的画面 / 论证，与当前推荐分开。
```

简介可直接复制，计数、推荐理由、素材缺口、研究限制放编辑区。普通宣传不用声明“不是某种内容”“不能保证某种效果”，只需准确承诺自己提供的内容。

完整包有独立的内容主题和传播策略，默认附发布时间；用户明确不要时间时省略。策略通常几句话足够，只有用户需要时展开分析。SEO优先时按 [搜索意图](search-intent.md) 列简短落位表，默认推荐流任务可将关键词融入文案，不强制报告。

## 封面图交付

触发条件见 SKILL.md。实际制作按 [封面设计](cover-design.md) 执行；不强制每个平台单独生图。同一创意适合多个平台时共用一套，只有用户要求或内容角度确实不同时另做版本。

优先用户指定目录；否则放在视频旁 `publish/<视频名>-covers/`，没有视频路径时放当前目录 `outputs/<主题名>-covers/`。新任务重名目录加 `-02`、`-03`，不覆盖旧图。每套包含：

- `cover-4x3.png`：默认 1600×1200 横版，实际检查宽高比。
- `cover-3x4.png`：默认 1200×1600 竖版，同一创意独立排版。
- `preview-grid.jpg`：用于人工检查的小尺寸并排预览；只有一条内容时注明双比例预览，有多条内容才称多选题主页模拟。
- `cover-notes.md`：主句及字符数、输入资料与视频版本、选定帧及采样位置、两版布局、实际像素、制作工具 / 提示词或模板源文件、实际检查和未验证项；简记主体路线、人物是否参与表达，以及保留或省略头像 / Logo / 署名的理由，不附加无数据的传播效果判断。
- `cover-style.md`：沿用或首次采用的账号配色、字体、识别特征、可选标识及层级，便于下次复用；分别记录系列识别与文字署名，不默认每条放头像。已有规范时引用其稳定路径，无需重复复制；仅在用户要求修改账号规范时更新原规范。
- `sources/`：采用的原始帧；有使用才保存。可编辑模板路径有生成时写入说明，不强制额外格式。

固定模板任务另保存 `brand.json`、`request.json`、所用素材 / 字体及许可、可编辑 HTML、`render-report.json`。首次定稿或用户要比较方向时，每个候选放独立目录，内含上述双比例封面，附 `review.html` 和双比例缩略比较图。选定后用 [定稿工具](cover-system.md#定稿导出) 新增纯封面文件夹及选择记录，不覆盖候选目录；不强制为日常已定模板的每条视频重新生成三个方向。

在对话中展示封面并提供绝对路径链接。完整包的封面区关联同套图片；只补封面时可单独交付 `cover-notes.md`，无需新生成完整发布包。仅更新某平台封面时只改该平台相关封面区与链接。原选标题、简介、标签和排期保持原样。

缺视频时可交付封面文字与设计方向，明确“待视频取材”；缺图像工具时交付可复用提示词，明确“尚未生成图片”。仅创建说明不代表上述图像已交付，不输出不存在的图片链接。

## 核对与局部更新

以 [标题策略](title-strategy.md) 核对吸引力与承接，以 [平台](platforms.md) 核对字段，实际计数标题与短标题。默认 `len(text)` 为 Unicode 码点计数；在编辑区说明它及内部长度目标不等于平台硬限制。有已核实表单规则时采用其口径。

数字、效果、价格、真实经历与引语有来源；修辞和主观推荐不用逐字寻找原句。保留原文有意义的署名，不补造原创声明或AI声明。原稿有依据不等于已独立核查；疑问集中列出。

研究记录区分方法文章、项目方法和实际作品。方法只需说明如何改变本次候选；样本数与可见指标仅用于真实作品。详细研究可另存发布包旁，见 [联网工作流](research-workflow.md)，不将引用塞进每段宣传。

保存遵循 SKILL.md。用户只换某平台标题时，仅改对应候选和推荐；主推速览若引用该标题，只同步对应标题单元格；其他文案、已选标题、排期不联动修改。用户只补时间时仅更新时间字段。新文件不覆盖旧包。
