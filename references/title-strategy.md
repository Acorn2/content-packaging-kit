# 先选角度，再写标题

## 1. 分开看三个问题

- **事实**：这份内容实际给了什么？这是兑现标题的依据。
- **角度**：让什么人因为什么欲望、顾虑、好奇或态度停下来？这是选题判断。
- **表达**：怎样用一句像人说的话，让这个角度变得有劲？这是标题写作。

“网站有三维模型”是事实；“想给孩子找点有意思的科普资源”是动机；“儿童科普网站，已经卷到这一步了？”是一种表达。不要先把功能写进标题，再编一段点击理由为它辩护。示例仅解释区别，不是默认模板。

对于陌生读者，先卖体验、欲望、谈资或问题；已经找同类产品的人才更可能关心功能差异。不能把产品差异设为所有标题的准入门槛。具体对象可由标题与封面共同辨认，但只要标题的任务要让标题独立可懂。

## 2. 扩展真正不同的角度

围绕同一素材探索几种有依据的方向，选择有吸引力的，不必填满清单：

| 方向 | 要找到什么 | 容易误判的写法 |
| --- | --- | --- |
| 强种草 / 愿望 | 读者会想要、想体验、想留住的东西 | 把“支持四项功能”当用户愿望 |
| 代言 / 态度 | 替读者说出一句有立场的话 | 为观点凭空捏造一个坏对手 |
| 反差 / 新鲜感 | 熟悉预期与实际呈现之间值得看的距离 | “连某个普通部件也有”自动等于反常识 |
| 乐趣 / 参与 | 想猜、想认、想比较、想发给朋友 | 虚构测试结果、挑战难度或参与人数 |
| 顾虑 / 省力 | 想做一件事却被某个门槛拦住 | 没有免费、免安装依据就承诺零成本 |
| 搜索 / 资源 | 对方正在找的答案、方法或可用物 | 所有受众都写成“正在搜资料的人” |

一个方向写几条，比一句话贴几个公式名更有用。若草案都围绕一个功能：换读者、换欲望或换立场，别继续替换动词。素材的普通事实也可以通过游戏化、态度和类比获得趣味，不要求每条都有知识上的惊天反转。

## 3. 校准表达，不把参考读成分类目录

读到参考标题时，辨认它的具体吸引力：说中了什么欲望，哪里有情绪或立场，哪一处信息没有说完，哪些词带来了语气。移植机制和力度，用自己的材料另写。只学“数字型、提问型”名称，会把强烈原例写成温和摘要。

允许直接的偏爱、戏谑和邀请，例如“这才叫……”“请把……卷起来”“……有福了”“……别太离谱”。不必替换成“有点意思、值得了解、可以帮助”。也可以靠冷幽默或一句干脆的判断取胜，不强制每句惊叹。

不得搬运他人的“我试了十天”“收入翻倍”“十万人收藏”等事实。没有验证的数字不能为了匹配参考结构而填进去。公式库见 [角度和表达工具](headline-formulas.md)。

## 4. 写候选，再做对比

多平台通常先写 12–20 条跨角度草案，再做平台适配；一平台或短请求按需缩减。普通交付无需展示整个草案池；维护 Skill / 分析失败时保存实际候选和淘汰理由，便于比较，不能声称生成了未记录的测试结果。

先去掉公式名、推荐标记与解释，比较标题本身。可按下列次序取舍，不打伪精确分数：

1. 对目标读者来说，哪条最容易产生“想看 / 想要 / 想回应”的冲动？明确是哪种动机。
2. 与次优候选相比，哪条的态度、悬念、利益或趣味更鲜明？如果只赢在功能写得全，还要重选。
3. 是否能快速看懂？不要为了新颖堆叠两个比喻，让人先猜标题是什么意思。
4. 内容能否兑现读者预期？再核具体主张、计数与平台字段。修正承诺后重新比较，不默认选择最温和的一条。

每个平台默认三个可竞争候选，主推可以是最直接的种草或最有态度的一句。候选不强制套“保守 / 平衡 / 激进”三档，也不强制每个平台使用不同公式。一个强角度可跨平台改写，不能为了去重牺牲表达。

## 5. 淘汰这些失败模式

| 失败模式 | 识别方式 | 修复方向 |
| --- | --- | --- |
| 功能摘要装感叹号 | “新增三项功能！太棒了！”删掉惊叹后没有欲望 | 重新选愿望、顾虑、态度或趣味 |
| 伪反常识 | 把目标读者早就知道或根本不关心的事写成惊天发现 | 转向更值得围观的呈现，或直接种草 |
| 泛夸赞 | “这个东西绝了”不知道对象，也没有封面补充 | 保留评价，补足对象或看点；别一律删情绪词 |
| 标题依赖长解释 | 只有读完推荐理由才理解为什么有意思 | 把最有劲的一点写进标题 |
| 同角度换词 | 三条分别“陪娃看、在家看、一起看” | 重选动机，不只改句式 |
| 过度自证差异 | 每条都得塞技术名、模型数和独有功能 | 将证据移到封面或简介，给标题留出表达空间 |
| 搜索词压过吸引力 | 需求词、品类词、品牌词挤成目录 | 按传播目标保留一个主要对象或意图 |

“换成别的产品也能用”只提示检查是否空泛，**不再作为淘汰标准**。同一种真实需求可以由多个产品满足，标题无需完成竞品论证。相反，一条独有功能标题也可能毫无吸引力。

用户说“没新意”时记录旧角度，避免近义改写；至少尝试一个不依赖旧卖点的方向。旧稿里的“推荐”标签不构成保留理由。两轮重写后仍有限，就交付当前最佳方案与具体素材缺口，不通过更长的分析假装解决。

## 6. 表达自由与兑现边界

修辞、主观好恶、拟人台词、假设场景不需要逐字来自素材。可以夸张体验和情绪；不能伪造事实或暗示不存在的功能。引号不能将“自动导入”这种能力变成无须核验的比喻。

- “这个配色太犯规了”：主观评价；保留。
- “所有设计师都在用”：真实使用规模主张；需要依据或改成对设计师的邀请。
- “我家孩子看得不肯睡”：实际家庭经历；无材料时换成推荐口吻。
- “为什么会这样”：需要内容有解释；纯展示可以换成感叹、提问参与或欣赏邀请。

题材本身适合强表达时，不因缺少用户量、成绩和亲测故事而停止宣传。没有实验、幕后或动态过程就不许诺它们；有模型、有对照、有资源，照样可以写强标题。

## 7. 标题之后

封面默认 4–10 字符作为排版起点，可按主题调整。标题给动机，封面突出画面或对照，首句接住同一期待；三处不必复读同一句，也不各讲一个无关卖点。

产品名、能力、入口在简介自然出现；行动只选一个。视频开头注明沿用 / 改剪 / 需补拍，当前推荐只依赖现有内容。图文关注首屏，不自动扩写全文。

这套筛选是编辑判断。用户偏好、可复制程度与发布效果分别验证，不将自评或公式分类写成实际流量证据。
