# 搜索意图与关键词

搜索 / SEO 优先、需要关键词落位时读取。本项目的 SEO 指发布文案中的搜索意图与自然用词，不扩展为网站代码、收录或排名优化。推荐流与搜索是两种阅读情境，不是五个平台已确认的算法分组。

## 先选用户会搜什么

从素材提取一个主题实体、一组受众需求和少量相关表达。先判断搜索者要的是资源、方法、解释还是具体产品，再判断当前内容能满足哪一种。

| 词的角色 | 假设素材：四阶段3D蝴蝶模型 | 假设素材：标签、备注、关键词找回网页 |
| --- | --- | --- |
| 主题词：辨认对象 | 蝴蝶、3D模型 | 网页收藏、链接管理 |
| 需求词：为什么找 | 亲子科普、蝴蝶观察 | 收藏找不到、整理收藏夹 |
| 长尾问法：具体任务 | 给孩子讲蝴蝶用什么模型 | 收藏的网页怎么找回来 |
| 品牌词：已知道产品的人 | 素材提供的真实产品名 | 素材提供的真实产品名 |
| 不承接的搜索意图 | 蛹内部变化原理、完整昆虫课程 | 自动整理、跨设备同步（未提供时） |

这是策划词表，未经查询不称为“热门词 / 低竞争词”。不为新产品名假定搜索量；不强迫标题容纳整个词表。素材薄时保留主题词即可。

用户要热门关键词、当前趋势或搜索量时，按 [联网研究工作流](research-workflow.md) 找对应平台公开结果或用户提供的数据。搜索建议、作品用词、搜索量是不同证据；外部搜索引擎结果不代表站内排序。无法取得量化数据时仍交付基于语义的词表，只标一次缺口。

## 同一内容写两种入口

- **推荐流优先（默认）**：鲜明点击理由 + 可识别对象。例如“这配色网站，审美也太会了吧”；无需每个标题加“亲子科普网站”。
- **搜索优先**：需求词 / 主题词 + 有吸引力的差异。例如“做海报不会配色？这个网站直接看搭配”——前提是素材确实提供配色参考。搜索者能认出资源，也知道为什么选它。
- **兼顾**：读起来自然才合并，例如“网页收藏总找不到？给链接加个搜索框”。不要把“网页收藏｜链接管理｜效率工具｜神器”当标题。

默认从推荐流角度选主推，有合适需求时保留搜索候选。用户明确要 SEO 时，先比较搜索意图是否匹配、对象是否清楚，再比较吸引力。词语位置服务阅读，不设置未经验证的关键词密度、出现次数或“前几个字加权”规则。

## 关键词落位

SEO优先或用户需要选词依据时，在编辑说明中列一张短表：`主意图 / 主题词 / 需求词 / 放在哪里 / 依据状态`。各平台有不同搜索角度时在表内注明；相同词不要复制五张表。普通推荐流任务自然落词即可，不强制输出选词报告。

1. 搜索候选自然包含一个核心对象或需求表达；推荐流候选保留可识别对象即可。
2. 简介首句承接利益；标题使用比喻时，接下来的自然句子补足实际对象与用途。
3. 正文用具体内容展开相关表达；话题选主题、场景、领域，品牌只在有用时加入。标题没放的词可以在这些位置出现，但不能据此保证收录或排名。
4. 不新增素材没有的教程、测评、免费下载等承诺来覆盖关键词；不自动改写图文全文。

只要标题时，候选的“点击理由”可简注“搜索：网页收藏”，不额外输出词表、标签、排期或 SEO 长报告。只改指定平台标题时，其他平台及正文保持原样。

## 方法依据

- [Google Search Central：标题链接](https://developers.google.com/search/docs/appearance/title-link)，2026-10-14 读取正文：网页标题应清楚、简洁，避免堆词和重复套话。只借鉴可读性，不把网页排名机制套到国内站内搜索。
- [Copyblogger：兼顾搜索与社交](https://copyblogger.com/search-social-optimize/)，2017-04-03 发布，2026-10-14 读取正文：借鉴明确主题与点击动机配合的写法。上述中文例句和落位流程为本项目的编辑方案，不是该文验证过的平台效果。
