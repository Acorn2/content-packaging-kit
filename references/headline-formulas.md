# 角度和表达工具

默认与 [标题策略](title-strategy.md) 一起读。公式帮助打开思路；不是每条必须填入功能名的模板。以下为原创结构示例，各自有说明的素材前提，不代表真实产品或已发布成绩。不要将这些题材当后续任务的默认主题。

## 七类方向怎样写出力量

| 方向 | 真正起作用的地方 | 原创示例与素材前提 | 写弱的误用 |
| --- | --- | --- | --- |
| 理想场景 | 让人想拥有一个具体状态，最好跨过原本的门槛 | “想拥有一片星空，先从这个屏幕开始”：素材是可交互星空页面 | “把功能展示出来”不等于愿望 |
| 损失厌恶 | 读者已有的时间、精力或机会正在白费 | “笔记越记越多，怎么一到要用就失忆？”：内容讨论笔记检索 | 任意小细节都称为“不看就亏” |
| 数字 | 将规模、反差或交付物压成易懂的形状 | “12张封面，一本书能换多少张脸？”：内容确有12版设计 | 给普通清单加数字就认为吸睛 |
| 反预期 | 读者熟悉的事物，出现了值得看的用法或呈现 | “一本菜谱，怎么做出了闯关游戏的味道”：确有逐关解锁式界面 | 用“竟然”宣布一个普通功能 |
| 提问 | 问的是读者想知道、想参与或想反驳的问题 | “周末只休两天，为什么行程要排得像出差？”：内容讨论休闲旅行规划 | 问一个常识，再把答案藏起来 |
| 参照 / 类比 | 借熟悉参照迅速传达体验或反差 | “这份会议纪要，简直是聊天记录的判决书”：内容确实提取决定、责任和截止时间 | 随便换一个容器名，称作创新 |
| 身份 / 人群 | 让特定人觉得这份内容值得偏爱 | “爱给角色换装的人，这个捏人页面别错过”：素材含换装演示 | 只有“新手必看”，不知道看什么 |

方向来自 README 中的中文参考文章，具体归纳和示例由本项目撰写。损失不是遗漏任意知识点，反常识不是所有功能都惊人，参照物也不只是一句“搬到家里”。

## 同一个角度，怎样放开表达

强宣传可以直接说偏爱、期待、不满和惊喜。不要只在弱摘要前加情绪词；先把角度写出来，再选择一句有力度的话。

| 弱写法 | 可以尝试的表达 | 关键变化 |
| --- | --- | --- |
| 分享一个配色工具 | 做配色的，请把这个网站卷起来 | 对特定人群直接推荐；正文需展示配色工具 |
| 待办清单整理方法 | 待办清单写成许愿池，难怪越看越心虚 | 说破行为与心情；原稿需讨论堆任务问题 |
| 夜景照片展示 | 这夜色，不拿来当壁纸真有点浪费 | 把欣赏变成想拥有；提供的画面需适合该用途 |
| 离线地图功能说明 | 没信号的时候，才知道这张地图有多香 | 切入使用处境；素材须支持离线地图 |

这些是表达示范，不强制所有标题用“卷、上头、神器、救命”。词不是禁词，也不是加上就有效。根据内容可以非常直白：“这个画画网站，值得给孩子留一个书签。”直接推荐如果比拐弯比喻更有说服力，应优先保留。

## 参考标题的迁移方式

不要只记分类。用四个短问题辨认参考：**它在卖什么欲望？替谁表态？留下什么未说完？语气有多直接？** 保留这个结构和力度，替换为自己的对象与情境。

- 看见“低成本获得理想体验”，先核对素材有没有真实的门槛差异；没有就保留愿望，换掉价格承诺。
- 看见“我试了很多次才发现”，学习发现式揭晓；没有本人经历就改成观察或邀请，不捏造试用次数。
- 看见“某人群有福了”，可以直接迁移推荐口吻，再给出具体对象；不必弱化成“或许适合”。
- 看见反转，先判断是知识反转、视觉反差还是态度反转；纯产品演示也能用后两种，不必冒充科学揭秘。

参考来源与实际阅读边界见 [来源库](source-library.md)；如何取得当前任务的参考见 [参考扩展](reference-expansion.md)。

## 组合而不堆砌

先选一个主角度，再用一种表达强化：大胆推荐、直接判断、拟人对话、熟悉类比、反问、具体场景都可选。避免一句话同时出现痛点、承诺、数字、身份、反转和行动号召。

“结构 → 情绪 → 用词”是打磨顺序：先看角度是否值得点，再强化态度与节奏，最后删弱词和拗口连接。若角度弱，换“有趣”为“炸裂”不能救回来。文字钩子与画面共同表达，按 [平台](platforms.md) 的实际入口适配，不把每个平台锁死成一种句型。
