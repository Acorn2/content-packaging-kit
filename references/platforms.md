# 平台与发布形式

## 规则状态

本文件的数值均为**内部写作目标**，用于生成简洁且便于编辑的草稿，不是已核实的平台当前硬限制。制定日期：2026-10-13。不同入口、账号和活动可能有不同要求；平台表单或官方资料核实的限制优先，并在输出的待确认项记录必要差异。

不要把“多 emoji”“必须短标题”“固定多少个标签”“无数量限制”当作已证实的平台规定。分区 / 话题名称是建议，不能承诺当前下拉列表中一定存在。未知的活动话题、话题 ID 和分类 ID 不编造。

## 官方资料与动态入口

来源、核验日期及可读取程度统一记录在 [来源库](source-library.md)，本文件只保留路由，避免重复维护限制数值：

- 知乎：ZH01 创作者手册；问题、文章与视频分开找同题材样本。
- 抖音：DY01 / DY02 的机制说明与当前更新；DY03 的原巨量算数入口已升级并跳转到抖音创作者中心，具体指数需按当前权限核验。
- 小红书：XHS01 创作平台 / 百科、XHS02 电商课程目录；XHS03 的商品笔记搜索指南只用于对应场景。
- B站：BL01 创作学院；本轮登录受限，不能依据未读课程新增硬限制。
- 视频号：WX01 助手与 WX02 待确认规范地址；本轮未取得后台规则，不能把公众号、直播或带货资料直接套到普通视频 / 图文。

联网增强时，优先官方资料与真实作品；商业产品 T01–T03 只是可选入口，不是默认数据依赖，估算、访问权限与题材适配均需说明。

## 默认字段

| 平台 | video：视频发布素材 | graphic：图文发布素材 | 内部写作目标 |
| --- | --- | --- | --- |
| 知乎 | 标题 ×3、视频简介、话题建议、封面文字 | 文章标题 ×3、摘要 / 导语、话题建议、封面文字；回答见下文 | 标题通常不超过 40 字符，简介 / 摘要约 100–250 字符，话题 3–5 个 |
| 微信视频号 | 标题 / 描述看点 ×3、推荐描述、短标题候选、话题、封面文字 | 图文入口配文、看点标题 ×3、话题、封面文字 | 看点标题不超过 30 字符；短标题不超过 16 字符；配文约 80–200 字符，话题 3–5 个 |
| B站 | 标题 ×3、简介、分区建议、标签、封面文字；按需给动态文案；要求章节且有可靠时间映射时给章节 | 专栏标题 ×3、摘要 / 导语、分类 / 标签建议、封面文字；动态见下文 | 标题通常不超过 40 字符，简介约 150–350 字符，标签 5–8 个 |
| 抖音 | 标题看点 ×3、推荐发布描述、话题、封面文字 | 看点标题 ×3、图文配文、话题、封面文字 | 看点标题不超过 30 字符，配文约 60–180 字符，话题 3–5 个 |
| 小红书 | 标题 ×3、笔记正文、话题、封面文字 | 标题 ×3、图文笔记配文、话题、封面文字 | 标题不超过 20 字符，正文通常 200–500 字符，话题 3–8 个 |

正文长度是目标区间，不是凑字任务。内容很简单时可以更短，复杂且有必要时可更长；明确的用户要求或已核实限制优先。标签是选择建议，不代表平台允许数量。

完整视频 / 图文素材包另附每个平台的发布时间建议，按 [发布时间建议](publishing-times.md) 选择首选、备选和休息日时段，注明时区、受众理由与依据状态。标题重写不自动改时间；视频时段不直接视为该账号图文或直播的实测最佳时间。

## 传播入口与联合设计

生成标题按 [标题策略](title-strategy.md) 先选角度，再使用 [表达工具](headline-formulas.md)。下表仅是探索起点，最终候选写读者点击理由，不必展示公式术语。不要因视频号就默认正式、因知乎就默认克制；允许自然的情绪、惊叹和适度夸张。

以下是可测试的编辑方向，不是固定用户画像或算法权重。按当前题材和目标选择，不把同一句产品介绍分发五次；标题、封面、简介首句联合设计，视频附最小开头建议。

| 平台 | 可优先探索的动机 | 容易写弱的方式 |
| --- | --- | --- |
| 知乎 | 问题、判断、方法、值得讨论的解释 | 标题问为什么，正文却只有功能罗列 |
| 微信视频号 | 家庭 / 生活场景，适合分享给某个人的具体价值 | 只有“新发现 / 陪伴”，封面看不出对象 |
| B站 | 可探索的体验、视觉展示、知识解释、创作者过程 | 只写产品名加“介绍”，缺少点击理由 |
| 抖音 | 即时可见的变化、反差、好奇，开头及时兑现 | 问题开场后立刻进入完整产品清单 |
| 小红书 | 可保存的资源、生活场景、可照做的方法 | 泛泛种草，无具体用途或使用步骤 |

产品宣传可强化比喻、情绪与场景，但新增实测、教程或解释必须有相应内容。搜索版本选择一个主要意图，自然放入标题与首句，不以堆关键词代替看点。

### 平台差异怎样落到成品

同一素材先分别回答下表的问题，再挑主推。标题、封面、首句要配合；这张表是编辑起点，用户的账号语气与题材优先，不是平台固定人群或算法结论。

| 平台 | 主推先回答什么 | 句子与配套文案 |
| --- | --- | --- |
| 知乎 | 哪个具体问题或判断值得展开？ | 可用鲜明观点或有价值的设问；简介立即给论点或资源，搜索词优先选问题对象 |
| 微信视频号 | 谁会想把它转给一个熟悉的人？ | 让体验或用途容易转述；短标题辨认对象，描述补充生活场景，不机械套亲子人群 |
| B站 | 哪个过程、奇观或梗值得打开看？ | 可以玩梗、做尺度反差；保留内容对象，别用同一套“我做了一个”冒充创作者经历 |
| 抖音 | 先看见哪句话，会想继续看眼前的变化？ | 把冲突、欲望或意外前置；封面和现有开头尽快接住，不额外承诺看不见的演示 |
| 小红书 | 哪个具体场景值得种草或留着用？ | 允许强烈评价和资源感；短标题保留对象与看点，正文用用途和操作补足搜索语义 |

同平台三个候选应有实质选择；跨平台允许复用强角度，再按长度、语气和入口适配。不要为了五个平台完全不同而选弱标题。SEO 的选词和落位统一见 [搜索意图与关键词](search-intent.md)。

## 知乎

让标题呈现一个明确问题、反常识结论或具体争议，配文接住观众为什么关心，再交代有价值的内容。不要强制专业腔，也不要虚构“高赞回答”或经历。现有视频缺少论证时，选体验 / 场景角度，不为了知乎标签强加争论。

- **视频**：简介概括实际覆盖点，不另写整篇回答。
- **文章**：默认只生成标题、摘要 / 导语及话题，保留原稿。
- **回答**：用户指定问题时，沿用该问题；输出回答开头 / 摘要与相关话题，三个标题作为可选传播看点，注明不是替换问题标题。没有指定问题时可给“可匹配问题方向”，不编造已存在的问题链接。

## 微信视频号

表达具体，突出观众为什么关心、适合与谁分享。可以使用口语、反问、鲜明情绪或体验比喻，不强制正式语气，也不禁止 emoji。

- **视频**：看点标题是候选表达；推荐描述为可粘贴发布文案，短标题单独给出。未核实前不声称它们都对应独立必填字段。
- **图文**：输出配文草稿与封面文字；用户没有给入口时，标为“图文发布配文，入口字段待确认”，不自动改成公众号文章，也不把该入口的可用性当作已验证事实。

## B站

对象与问题清楚，标题可以有悬念、冲突或反差。产品名不必放第一位，体验和看点可先出现；教程、研究、故事、讨论各用合适角度，不统一添加“保姆级”“深度测评”。

- **视频**：给最匹配内容的分区建议并简短解释；未核实时标为建议。标签单独用顿号分隔，方便复制，不加 `#`，不凑固定数量。
- **专栏**：输出标题、摘要 / 导语、分类与标签建议，不把长文摘要当视频简介。
- **动态**：用户指定动态时输出短动态配文，三个看点标题作为可选开头，不伪装成独立标题字段。
- 无可靠时间证据不输出章节时间；不自动添加三连或网站引流。

### B站视频章节

仅在用户要求章节且有可靠时间映射时生成。可靠依据可以是用户确认对应最终成片的“时间点 → 内容”列表，或与最终成片一致的分镜 / 剪辑时间表；仅有草案、估算时长或原稿段落顺序不够。

- 采用从最终视频起点计算的章节起始时间，使用 `MM:SS 标题`；一小时以上使用 `HH:MM:SS 标题`。这是便于复制的交付格式，不声称已验证当前平台章节字段。
- 起始时间递增、无重复且不为负；已知最终时长时，章节起点必须小于该时长。未知时长时说明未核对视频末尾范围。
- 章节标题与对应内容相符，时间单位、起点或成片版本存在歧义时不猜测。保留可靠部分，仅将受影响章节标为待确认。
- 不按字数、语速、段落数量或估算旁白时长推算时间点，不自动转写或解析视频。没有可靠映射时省略章节并说明缺口，不妨碍生成标题、简介和标签。
- 输出中单独给出时间依据及对应成片版本（已提供时），与可复制章节列表分开；没有检查视频文件时不声称已完成成片对时。

## 抖音

把一个最值得关注的矛盾或利益点放在开头，避免简介重复整个原稿。看点标题可并入发布描述，不假设当前表单一定有独立标题与简介字段。

- **视频**：推荐发布描述承接视频内容，话题另列。
- **图文**：配文概括图片实际覆盖的内容，不默认生成图卡页或口播脚本。

## 小红书

采用具体场景、问题、反差或讨论入口；不同题材允许不同语气，不把所有内容改成种草，不强制 emoji 或特殊标点。

- **视频**：笔记正文补充观看价值与实际覆盖点，不伪装成作者亲测。
- **图文**：输出配文，保留图卡 / 原稿中的事实；不默认重写全文或创建图片。
- 话题单独以 `#话题` 输出，避免重复堆词。

## 复制格式

B站标签：`主题一、主题二、主题三`。其他平台的话题：`#主题一 #主题二 #主题三`；知乎另给纯话题名列表，供表单搜索选择，不能承诺纯文本就能绑定话题。

普通文案任务的封面文字为文本建议，不代表已经生成封面。用户要求封面图，或提供视频并要求完整视频发布包时，按 [封面设计](cover-design.md) 实际制作 4:3 与 3:4 两版；只要标题或只改文案不触发。双比例是交付约定，不是已核实的五平台入口规范；实际上传裁切需要对应入口核对，不自动上传。
