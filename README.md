# 看点工坊

**Content Packaging Kit**

### 从一份内容，准备有看点的标题、封面与发布文案。

面向内容创作者、独立开发者与产品推广者的 Codex Skill。

**知乎 · 微信视频号 · B站 · 抖音 · 小红书**

视频剪好了，文章写完了，发布前还要想标题、写简介、挑封面，再为不同平台调整一遍。

看点工坊读取你的讲稿、产品资料或视频，先找到目标观众想看的理由，再围绕这个看点制作标题、封面与发布文案。你可以只要几个标题，也可以准备一套多平台发布材料，最后按自己的判断选用。

## 核心能力

### 先找看点，再写标题

从人群、欲望、顾虑、反差、乐趣与搜索需求出发，比较不同的观看动机。每个平台默认精选三个标题，推荐一个，并说明为什么选它。

你可以要求更直接的种草、更鲜明的观点或更强的悬念；产品功能、数字、价格与真实经历仍由素材承接。

### 标题、封面与简介围绕同一看点

在完整发布包中，标题吸引目标观众，封面突出内容对象，简介接着说明会看到什么。按平台补齐配文、话题、分类等适用字段，减少发布前来回拼接材料的工作。

需要搜索流量时，也可以围绕具体任务组织关键词；完整包可附发布时间建议，作为后续结合账号数据调整的起点。

### 封面既突出本条内容，也延续账号风格

从视频和讲稿中选素材，沿用你满意的参考、字体和配色。连续制作时复用已确认的账号规范，让不同选题有区别，也保持视觉上的联系。

- **按题材选主角**：内容对象、真实人物或二者结合；头像、Logo 与署名按表达需要和账号规范使用。
- **横竖分别构图**：默认提供4:3（1600×1200）和3:4（1200×1600），也可只要其中一版。
- **文字与素材分别制作**：已有截图或插画优先复用，固定模板控制中文排版；需要新主体时再使用图像工具。
- **看过缩略图再选择**：检查文字、主体、遮挡与小尺寸效果；本地审阅页支持图片下载和选择记录。

### 修改哪里，就保留其他已选内容

标题、文案和封面可以单独使用，也可以在已有发布包上继续调整：

> “只换抖音标题。”
>
> “只补封面，保留原来的简介和标签。”
>
> “把品牌名换成星河工作室，其余不动。”

按请求更新对应平台或字段，保留其他已选内容和旧输出，方便比较与回退。

## 快速开始

### 1. 安装 Skill

在 Codex 中发送：

```text
使用 $skill-installer，安装 https://github.com/Acorn2/social-creator-toolkit。
Skill 位于仓库根目录，安装名称指定为 content-packaging-kit。
```

安装完成后，在后续对话中调用 `$content-packaging-kit`。界面名称为“看点工坊 · 标题、封面与发布文案”。

### 2. 给它一份素材和一个目标

粘贴正文，或将下面的路径替换为你的文件：

```text
使用 $content-packaging-kit，读取 <讲稿或产品资料路径>，
面向第一次了解这个产品的人，给小红书和B站各写三个标题，
推荐一个，并附可以直接使用的简介与话题。
```

### 3. 需要封面时，再交代视觉参考

```text
使用 $content-packaging-kit，读取 <视频路径> 和 <讲稿路径>，
制作标题、发布文案与4:3、3:4封面。
参考 <满意封面或账号规范路径>，署名用“星河工作室”。
```

讲稿和视觉参考均可按现有资料提供；没有参考时，会先采用一套适合题材的方案。只要标题或文字文案时，不触发封面制作。

## 使用场景

| 你正在做什么 | 可以怎么要求 | 会得到什么 |
| --- | --- | --- |
| 给产品做第一轮宣传 | “面向有这个困扰的人，写标题与介绍文案。” | 不同传播角度的标题候选、主推与发布文案 |
| 把同一内容发到多个平台 | “根据这份讲稿，准备五平台视频发布包。” | 按平台组织的标题、简介、话题及适用字段 |
| 为连续视频做封面 | “沿用账号规范，给新视频制作双比例封面。” | 两版PNG、缩略预览、设计说明及所用素材 |
| 想获得更明确的搜索入口 | “标题覆盖‘网页收藏找不到’这个需求。” | 围绕任务与搜索意图组织的候选 |
| 已有发布包，只想局部调整 | “只换小红书标题，其他字段保持原样。” | 对应平台或字段的更新 |

## 交付与使用条件

### 拿到什么

仅要标题时直接在对话交付；完整发布包保存为Markdown，方便审阅与复制。封面按请求导出PNG、缩略预览与设计说明；固定模板流程另保留可编辑HTML、配置、字体许可及渲染报告。

你指定的保存目录优先。默认保留原文与旧版本；完整字段和路径约定见 [输出契约](references/output.md)。

### 使用条件

| 任务 | 需要什么 |
| --- | --- |
| 标题与发布文案 | Codex 和可读取的资料；文本可直接粘贴 |
| 视频取材 | 本地视频，以及环境已有的Python 3、FFmpeg / FFprobe |
| 固定模板封面 | 环境已有的Node.js、Playwright / Chromium，以及可用的本地图片 |
| 新插画或视觉主体 | 当前环境可用的图像生成或编辑工具 |

Markdown / TXT可直接读取；DOCX / PDF使用环境可用的提取能力。项目没有需要启动的应用服务，不绑定某家生图服务，也不自动安装依赖。缺少图片素材或工具时，会明确交付到哪一步。

4:3与3:4是本项目的默认交付规格，具体平台入口的裁切仍需核对。看点工坊负责发布前的创作与本地交付，上传和发布由你完成；传播结果需要实际账号数据验证。
