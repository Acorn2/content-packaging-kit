# 标题参考库
# 标题生成或重写时默认读取已有记录；没有记录时使用 references/headline-formulas.md。
# 借鉴表达结构与看点，不照抄，不把示例当作成功案例。
# 用户选择过的标题不等于流量表现好的标题。
# 无需为使用本 Skill 提前填写这个文件。
#
# 建议每条真实参考记录注明：
# 平台、发布形式、题材、标题、来源链接、发布时间、观察时间 / 时长、数据。
# 数据可包含曝光、点击 / 播放、阅读 / 完播、互动等实际可获得指标。
# 注明指标来自作品页面、自有后台还是第三方预估，保持各自口径。
# 可见时记录作者规模、封面与标题版本，避免把内容或封面变化算成标题效果。
# 没有数据时注明“仅供表达参考”，不要推算 CTR 或爆款概率。
# 来源目录与动态采样方法见 references/source-library.md 和 references/research-workflow.md。
#
# 格式示意（不是实际发布结果）：
# 平台：B站
# 发布形式：视频
# 题材：填写实际题材
# 标题：填写实际标题
# 来源：填写真实链接或用户提供的资料
# 发布时间 / 观察时长：未提供
# 效果数据：未提供；仅供表达参考
