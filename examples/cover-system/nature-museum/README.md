# 自然博物馆：图1风格标准封面

用户已明确指定此前满意的双比例封面作视觉参考。本轮只实施这一方向：保留“把自然博物馆 / 搬进家里”、黄色蝴蝶、绿色毛毛虫与叶片、平涂粗线条、蓝黄暖白和饱满构图；按固定字体与模板导出横竖两版。主句去掉换行共10字。

`request.json` 是当前单方向请求，`brand.json` 是对应账号规范。原视频为用户提供的约68秒自然博物馆概念插画视频。[输入视频与后续宋体精修封面案例](../../nature-museum-case/README.md) 已单独收录；本目录保留原有固定模板与回归素材，不代表后续精修版的排版配置。本目录没有传播结果或点击率证明。

## 固定规范

- 本地思源黑体：主标题Heavy/900，辅助Medium/500，栏目和署名600；字体SHA-256与SIL OFL许可保留在配置及项目字体目录。
- 横版普通行142px、强调行196px；竖版普通行162px、强调行196px。112px起点经参考图比例校准后调整，确定的数值写入两套配置，不逐张随机变化。
- 辅助36px、栏目28px、署名26px；安全边距72px。暖白底、墨色普通行、蓝色强调行、单处黄色底线。
- 两个主体独立定位，保留原色、完整轮廓。仅一款固定蓝色虚线箭头，不随机添加装饰。
- 标准预览页直接并排展示横竖两版；不强制重选三个传播方向。

## 素材

`butterfly-flat.png` 与 `caterpillar-flat.png` 于2026-10-14用内置imagegen，以用户认可的原横版封面作参考，分别提取 / 重绘无字透明主体。保留平涂粗线条，不采用上一轮彩铅质感。不是逐像素原图抠图，微小轮廓仍可能与原生成图不同。用确定性裁切去掉透明外边，不改变主体色彩或轮廓；最终绘制保持原始比例。

准确提示词见 `standard-generation-prompts.json`。插画是概念示意，不是产品真实三维模型或网站界面。代码许可不替代字体和图像服务自己的条件。
