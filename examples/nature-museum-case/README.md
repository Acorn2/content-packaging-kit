# 自然博物馆：视频与封面效果

本例将用户提供的亲子科普视频与在本项目中制作、迭代的封面放在一起，方便对照输入内容和输出效果。视频展示蝴蝶生命周期、观察角度及其他自然主题；封面提炼“把自然博物馆搬进家里”这一体验表达。

![把自然博物馆搬进家里](cover-4x3.png)

[查看 / 下载输入视频](nature-museum-narrated.mp4) · [查看封面原图](cover-4x3.png) · [打开对照预览页](preview.html)

`preview.html` 使用原生视频播放器，无外部依赖。克隆仓库后直接用浏览器打开即可播放；在 GitHub 等代码托管页面上，HTML 源文件链接不一定渲染为网页，视频链接也可能需要先下载。

## 输入与输出

| 文件 | 作用 | 实际规格 |
| --- | --- | --- |
| `nature-museum-narrated.mp4` | 输入视频，原文件副本 | 约68.17秒，1920×1080，30fps，H.264 视频 / AAC 音频，约4.5 MiB |
| `video-poster.jpg` | 视频预览图 | 从约20秒处采样，1920×1080；不代表整个视频或封面成品 |
| `cover-4x3.png` | 输出效果封面 | 1600×1200，4:3，采用本次宋体精修版 |
| `preview.html` | 视频与封面对照页 | 浏览器播放视频、查看和下载原图；窄屏自动上下排列 |
| `media-manifest.json` | 文件核对记录 | 媒体规格、采样位置、文件大小及 SHA-256，不含用户本机绝对路径 |

本例按用户要求仅制作 4:3，未生成 3:4，不将横版裁切或拉伸后冒充另一版。视频是本 Skill 的输入素材，不是由本 Skill 生成的视频。

## 封面设计

- 内容主角是蝴蝶与毛毛虫，不额外添加作者头像；署名 `Hresh赫什` 只属于本案例账号，不是其他用户的默认值。
- 主标题使用宋体，动作句使用黑体；暖米色、蓝灰与浅麦色构成层次，拱形背景组织主题插图。
- 插图来自 [原固定模板示例](../cover-system/nature-museum/README.md) 的无字透明主体，是概念插画，不是真实网站界面截图或真实三维模型。
- 该图经过参考选择与局部精修。通用模板仍是另一套思源黑体排版，运行其示例命令不会原样得到这张宋体封面；本案例提供输入与最终效果，不包装成单命令复现包。

标题“把自然博物馆搬进家里”共10字，是内容体验的比喻，不承诺实际搬运、学习效果或视频未展示的功能。

## 素材来源与使用边界

视频由用户提供，原文件名为 `nature-museum-narrated.mp4`，来自用户的 Frame Loom 案例；本次原样复制，未重编码、裁切或改变音轨。封面为本项目对话中制作的宋体精修版，复制 PNG 时未改动内容。宋体使用系统安装的 Songti SC，系统字体文件没有复制或分发；黑体与插画来源见上方原示例说明。

媒体用于说明工作流与视觉输出，不是已验证的热门作品或传播成绩。仓库代码许可证不替代视频、插图和字体各自的适用条件。
